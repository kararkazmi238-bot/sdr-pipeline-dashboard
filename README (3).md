# 📊 SDR Pipeline & Activity Dashboard

A production-grade **Sales Development Representative portfolio dashboard** built to demonstrate real-world SDR skills including pipeline management, outreach activity tracking, lead qualification, quota attainment, and multi-channel conversion analysis.

**Live Demo:** [View Dashboard](https://kararkazmi238-bot.github.io/sdr-pipeline-dashboard)

---

## 🎯 What This Demonstrates

This project showcases skills directly relevant to SDR, BDR, and Sales Operations roles:

| Skill | How It's Demonstrated |
|---|---|
| **Pipeline Management** | Full funnel from prospected → connected → qualified → meeting set → showed |
| **Quota Attainment** | Visual gauge tracking meetings booked vs monthly target |
| **BANT Qualification** | Lead scoring across Budget, Authority, Need, and Timeline |
| **Multi-Channel Outreach** | Performance tracking across cold call, email, LinkedIn, and sequences |
| **Activity Logging** | Detailed outreach log with prospect title, touch type, and outcome |
| **Sequence Management** | Active cadence tracker with step completion visualization |
| **Weekly Trend Analysis** | 8-week activity volume chart across all outreach channels |
| **Pipeline Value Tracking** | ARR potential mapped at each funnel stage |

## 📈 Dashboard Features

### KPI Summary Row
- Meetings booked, outreach touches, connect rate, pipeline created, qualified leads, avg response time — all with week-over-week trend indicators

### Pipeline Funnel
- 5-stage funnel: Prospected → Connected → Qualified → Meeting Set → Showed
- Stage conversion rates and pipeline ARR value at each stage

### Quota Attainment Gauge
- Visual arc gauge showing % of monthly meeting target achieved
- Breakdown: meetings booked, target, days remaining, daily pace needed

### Activity Log
- Last 20 outreach touches with prospect name, title, touch type, and outcome
- Color-coded outcome badges: Booked, Replied, Voicemail, No Answer, Nurture

### Channel Performance
- Side-by-side reply/connect rates for cold call, cold email, LinkedIn, and sequences

### BANT Qualification Scorecard
- Budget, Authority, Need, Timeline confirmation rates across qualified lead pool

### Weekly Activity Chart
- 8-week grouped bar chart: calls, emails, and meetings by week

### Sequence Tracker
- 5 active cadences with step completion progress bars and reply rates
